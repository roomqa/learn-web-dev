# MOSS Beauty Atelier — выбор даты и времени (React)

Практическое задание №3: перевод интерактивной страницы выбора даты и времени
на фреймворк **React** с использованием хуков состояния (`useState`) и JSX-рендеринга списков через `.map()`.

## Как запустить

1. Установите зависимости:
   ```bash
   npm install
2. Запустите сервер разработки:
   npm run dev
3. Откройте в браузере адрес, указанный в терминале (обычно http://localhost:3000)
