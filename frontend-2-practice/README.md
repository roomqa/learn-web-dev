# MOSS Beauty Atelier — выбор даты и времени (JS)

Вторая часть практического задания: оживление страницы выбора даты и времени на чистом JavaScript без фреймворков.

## Как запустить

Откройте `index.html` в браузере двойным кликом или через расширение **Live Server**.

## Что работает

- По умолчанию выбран день `17 октября 2026` и слот `14:30`.
- Кнопки `‹` и `›` переключают месяцы вперед и назад.
- Прошедшие дни и выходные мастера заблокированы (`disabled`).
- Клик по свободному дню выделяет дату, сбрасывает старое время и обновляет доступные слоты.
- Клик по слоту времени выделяет его и обновляет итоговую плашку и нижнюю панель.
- Кнопка «Продолжить →» сохраняет выбранные параметры в `localStorage`.

## Файлы

- `index.html` — разметка страницы
- `styles.css` — стилизация и состояния элементов
- `script.js` — состояние, чистые функции, рендер календаря/слотов и обработчики событий
