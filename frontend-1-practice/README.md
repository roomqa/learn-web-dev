# MOSS Beauty Atelier — выбор даты и времени

Итоговое практическое задание по вёрстке: страница выбора даты и времени
в пути записи клиента в салон красоты **MOSS Beauty Atelier**.
Только семантическая вёрстка (HTML + CSS) без использования JavaScript.

---

## Как открыть

Двойной клик по файлу `index.html` — страница откроется в браузере.
Дополнительная сборка или установка зависимостей не требуется.

Для удобной проверки через **Live Server** (в VS Code или WebStorm):
кликните правой кнопкой мыши по `index.html` → «Open with Live Server».

---

## Что внутри

- **Шапка (`header`)** — логотип салона, навигационное меню, кнопка помощи и индикатор прогресса бронирования (Шаг 4 из 6).
- **Верхняя панель управления** — кнопка возврата на предыдущий шаг и бейдж выбранной услуги («Стрижка · 60 мин»).
- **Карточка календаря** — сетка на октябрь 2026 года с разделением на свободные, занятые (недоступные) и выбранную дату (`17 октября`), а также легенда состояний.
- **Карточка слотов времени** — сетка доступных интервалов времени на выбранный день, счётчик свободных слотов и итоговая плашка с деталями выбора (дата, время, мастер и стоимость).
- **Нижняя панель действий** — уведомление о часовом поясе и кнопка перехода к следующему шагу («Продолжить →»).
- **Подвал (`footer`)** — адрес салона, график работы и ссылки для связи в мессенджерах и по почте.
